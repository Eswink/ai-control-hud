Scope: Agent UI only. Central Hub administration UI is intentionally excluded.

Language direction: Simplified Chinese is a first-class locale; English is the fallback locale. Technical product names such as ZCode, CommandCode, Agent, Hub, TTS and AUTO remain untranslated where appropriate.

The image contents are visual references. Values shown in the mockups are synthetic and must not be treated as API fixtures or requirements to fabricate fields that are not available from the canonical schema.

The binary originals are preserved in the UI reference delivery bundle associated with this design checkpoint. `docs/UI_DESIGN_PLAN.md` is the canonical implementation plan.
